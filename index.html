I'm Nicole Primero, a 4th-year BSIT Student.

This webpage serves as the final submission for Activity 3: Creating an HTML File and Managing Version Control with Git. The primary objective of this laboratory exercise is to demonstrate proficiency in basic web development and fundamental software version control practices.

As an IT student specializing in web and system development, understanding version control systems like Git and remote platforms like GitHub is essential for collaborative software engineering, tracking code revisions, and maintaining clean codebases.

Activity Breakdown & Objectives

  • Part 1: HTML Document Creation & CSS Styling

    Structured semantic HTML5 markup and created an external CSS stylesheet to apply clean layout styling, typography, and card containers.

  • Part 2: Version Control via Git (Staging & Commits)

    Initialized a local Git repository, configured workspace user tracking, staged modified files, and created detailed commit logs representing key development milestones.

  • Part 3: Remote Repository Integration (GitHub)

    Connected the local Git repository to a remote GitHub server, created the primary branch, and pushed local updates to the cloud for public review.

Git Commands Used in This Activity

  • git init — Initialized local repository
  • git add index.html style.css — Staged project changes
  • git commit -m "feat: complete activity 3 structure and styles" — Saved staged snapshot
  • git push -u origin main — Uploaded commits to remote repository
